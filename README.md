# Chengxue Li Personal Webpage

A simple static personal webpage for Chengxue Li, focused on quantitative fisheries science, stock assessment, Spatial Management Strategy Evaluation, and aquatic ecosystem modeling.

## Edit Content

Open the individual `.html` pages to update each top tab:

- `index.html`: About
- `research.html`: Research topics
- `projects.html`: Current projects
- `publications.html`: Publications and reports
- `teaching.html`: Courses taught
- `fieldwork.html`: Fieldwork and scientific cruises
- `service.html`: Professional service, honors, and awards
- `contact.html`: Contact information

The homepage uses `assets/hero-marine-research.png` as the hero image and `assets/Selfie.png` as the portrait. Other pages use generated marine or research backgrounds named `assets/hero-*.png`. The Research page uses original generated visuals in `assets/research/paper-*.webp`; it does not reference figures extracted from publications.

## Preview Locally

Open `index.html` in your browser.

## Publish With GitHub Pages

1. Create a GitHub repository named `your-username.github.io`.
2. Add these files to that repository.
3. Push to the `main` branch.
4. Visit `https://your-username.github.io`.

For a project repository instead of a user site, enable GitHub Pages in repository settings and select the `main` branch.
